# 5 分钟上手

## 启动

1. 已安装依赖（见根目录 `README.md`）  
2. 双击 `启动_CTE计算器.bat` 或 `start_app.bat`  
3. 浏览器打开界面  

---

## 路径 A：最快（直接填单相 CTE）

1. **输入方式** 选「直接填单相 CTE」  
2. 填相1 / 相2 名称、体积分数 f₁（f₂ 自动）  
3. 填两相 CTE（单位 10⁻⁶/K）  
4. 填 E、ν（并联需要；两相 E 相同则并联=串联）  
5. 点 **计算 CTE**  
6. 看「串联 vs 并联」对照与全部模型表  

---

## 路径 B：XRD 晶面加权（本项目常用）

1. **输入方式** 选「晶面族 + 峰面积加权」  
2. 确认 R 含义：默认 **I = 峰面积 / R**（与 no_LP 口径一致）  
3. **相1（β）**  
   - 内置 R 表选「β-Ti · R_no_LP」→ **填充本相 R**  
   - 在全宽表格中填：晶面、α、峰面积（R 已填可改）  
4. **相2（α″）**  
   - 选 Shuffle-58 或 Shuffle-73 → 填充  
   - 填 α 与峰面积  
5. 体积分数、E 同上  
6. **计算 CTE**  

晶面写法示例：`(1 1 0)`、`(110)β`、`(0 2 0)α"` 均可匹配内置库。

表格太矮：拖动「晶面表显示高度」滑条。

---

## 结果怎么读

| 名称 | 含义 |
|------|------|
| 相表观 CTE | 该相 XRD 加权结果，**不是**严格本征宏观 CTE |
| 串联 ROM | α = f₁α₁ + f₂α₂ |
| 并联 | E 加权；E₁=E₂ 时等于串联 |
| 模型区间 | 多模型并存时的离散范围，非误差棒 |

界面顶部可展开 **「读数必读：三层 CTE」**：晶面 α_hkl → 相表观 → 复合有效。  
顶部还有 **术语芯片**（鼠标悬停看定义）与 **术语词典**（中英对照表）。  
未计算时结果区有 **四步流水线示意** 与串并联示意图。  
点 **计算 CTE** 后会 **自动滚到结果区**；也可点「↓ 跳到结果区」。

导出：结果区折叠「导出」→ JSON / CSV / Excel。

---

## 侧边栏（工程与模板）

- **结构模板**：Al–SiC 教学 / β–α″ 结构骨架 / 纯 ROM 空白  
- **导入工程 JSON**：支持「仅输入」导出或完整 `cte_result.json`（自动取 phase1/phase2）  
- **恢复上次成功计算的输入**  
- CTE **显示**单位、有效数字（输入 CTE 仍按 **10⁻⁶/K**）  
- **R 匹配策略**：未匹配默认阻止计算；可改为警告后仍算，或勾选确认未匹配  

导出区另有 **仅输入 JSON（可再导入）** 与含 `model_interval` / `r_match_reports` 的完整包。

## 批处理（命令行，可选）

ZTE 类 Excel 分析脚本：

```bash
py -3 scripts/compute_zte_cte.py
```

输出默认在 `results/analysis_ZTE/`。  
Excel 路径可用环境变量 `ZTE_XLSX` 指定。
