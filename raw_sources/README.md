# raw_sources — 原始备份（非运行必需）

本目录存放**原始数据备份**，程序**不依赖**这里的路径。

| 子目录 | 内容 |
|--------|------|
| `r_csv/` | 用户提供的 α″ R 表原始 CSV（Shuffle-58 / 73） |

**运行时使用的 R 库**在：

`cte_app/data/r_libraries/`

换电脑时：拷贝整个项目即可；无需再拷 `E:\文件备份\...` 等外部路径。  
若需复现 ZTE 批处理分析，可将 Excel 放到 `raw_sources/zte/` 或设置环境变量 `ZTE_XLSX`。
